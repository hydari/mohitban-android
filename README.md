# محیط‌بان — همراه محیط‌بانان، برای طبیعت ایران

اپلیکیشن اندروید کاملاً آفلاین برای ثبت هزینه سوخت خودرو و موتورسیکلت‌های سازمانی، ساخت فرم رسمی هزینه سوخت (PDF و تصویر) و گزارش فصلی بر پایه تقویم جلالی.

- زبان و چیدمان: کاملاً فارسی و راست‌چین
- تقویم: جلالی (شمسی) در همه تاریخ‌ها، انتخابگر تاریخ و گزارش‌های فصلی
- واحد پول: ریال با جداکننده سه‌رقمی
- اینترنت: لازم نیست (اپ مجوز اینترنت ندارد)
- فناوری: Kotlin، Jetpack Compose، Material 3، Room، Coroutines/Flow، Navigation Compose، PdfDocument

---

## ساخت APK با GitHub (بدون نصب Android Studio)

1. در github.com یک حساب رایگان بسازید (از داخل ایران ممکن است به فیلترشکن نیاز باشد).
2. یک مخزن جدید بسازید: **New repository** ← یک نام (مثلاً `mohitban`) ← گزینه **Private** ← **Create repository**.
3. روی **uploading an existing file** بزنید و **همه پوشه‌ها و فایل‌های پروژه** (محتوای داخل پوشه `mohitban`، نه خود فایل zip) را بکشید و رها کنید، سپس **Commit changes**.
   - اگر پوشه `.github` آپلود نشد (برخی سیستم‌ها پوشه‌های نقطه‌دار را پنهان می‌کنند): در مخزن به **Add file ← Create new file** بروید، نام فایل را دقیقاً `.github/workflows/build-apk.yml` بنویسید و محتوای همین فایل از پروژه را در آن بچسبانید.
4. به زبانه **Actions** بروید. ساخت به‌صورت خودکار شروع می‌شود (یا روی **ساخت APK ← Run workflow** بزنید).
5. پس از حدود ۵ تا ۱۰ دقیقه، روی اجرای سبز‌رنگ بزنید و از بخش **Artifacts** فایل `Mohitban-APK-…` را دانلود کنید. داخل آن فایل APK است.
6. APK را به گوشی منتقل و نصب کنید (در صورت درخواست، «نصب از منابع ناشناس» را برای همان برنامه مجاز کنید).

> هر بار که فایلی را در مخزن تغییر دهید، APK جدید ساخته می‌شود. کلید امضای ثابت به‌صورت رمزگذاری‌شده در `signing/mohitban.jks.enc` است و رمز آن فقط در Secret مخزن با نام `MOHITBAN_KEY_PASSWORD` نگهداری می‌شود، پس هر نسخه جدید روی نسخه قبلی **به‌روزرسانی** می‌شود و اطلاعات از بین نمی‌رود. کلید در کد عمومی وجود ندارد.

## ساخت با Android Studio

1. Android Studio (نسخه Ladybug یا جدیدتر) را نصب کنید.
2. **File ← Open** و پوشه `mohitban` را انتخاب کنید و صبر کنید Gradle همگام‌سازی شود.
3. از منوی **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)** را بزنید.
4. فایل در مسیر `app/build/outputs/apk/` ساخته می‌شود.

## فونت

فونت وزیرمتن (مجوز آزاد OFL) هنگام ساخت به‌طور خودکار در `app/src/main/assets/fonts` دانلود می‌شود. اگر اینترنت در دسترس نباشد، اپ با فونت سیستم ساخته می‌شود. برای قرار دادن دستی، فایل‌های `Vazirmatn-Regular.ttf`، `Vazirmatn-Medium.ttf`، `Vazirmatn-Bold.ttf` و `Vazirmatn-Black.ttf` را در همان پوشه کپی کنید.

## ساختار پروژه (Clean Architecture)

```
app/src/main/java/ir/mohitban/app/
├── core/          تقویم جلالی، اعداد فارسی، ریال، عدد به حروف، اعتبارسنجی کد ملی و موبایل
├── domain/        مدل‌ها (پلاک قرمز خودرو/موتور، ثبت سوخت، خلاصه فصلی) و قرارداد مخزن‌ها
├── data/          Room (جدول‌ها، DAO)، مخزن‌ها، ذخیره تصاویر، پشتیبان‌گیری zip
├── pdf/           فرم رسمی A6 هزینه سوخت (PDF + PNG) و گزارش فصلی A4
├── receipt/       تشخیص آفلاین لبه رسید و صاف‌کردن پرسپکتیو
└── ui/            تم، کامپوننت‌های مشترک، صفحه‌ها و ViewModelها، ناوبری
```

## تغییر نرخ سوخت

از **تنظیمات ← نرخ سوخت** سه نرخ بنزین و نرخ گاز CNG قابل تغییر است و نیازی به ساخت APK جدید نیست. ثبت‌های قبلی با نرخ خودشان باقی می‌مانند.

## پشتیبان‌گیری

از **تنظیمات ← ساخت فایل پشتیبان** یک فایل zip شامل همه اطلاعات، امضاها و رسیدها ساخته می‌شود. با **بازیابی از فایل پشتیبان** روی هر گوشی دیگری برمی‌گردد.
